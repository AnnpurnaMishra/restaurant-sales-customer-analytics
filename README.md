# 🍽️ Restaurant Sales & Customer Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Restaurant Sales & Customer Analytics Dashboard** built using **Microsoft Power BI**, with data prepared and managed using Excel.

The dashboard helps analyze restaurant sales performance, order trends, menu item performance, customer ratings, and location-wise insights through interactive visualizations.

## 🎯 Project Objectives

- Analyze restaurant revenue and order trends.
- Evaluate menu item performance.
- Understand customer ratings and feedback.
- Compare performance across locations.
- Identify month-wise and day-wise patterns.
- Analyze orders by order type.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Data visualization and dashboard development
- **DAX** — Measures and calculations
- **Microsoft Excel** — Data preparation and analysis

## 📊 Key Dashboard Features

- Revenue and order analysis
- Menu item performance analysis
- Customer ratings analysis
- Month-wise and day-wise trends
- Location-wise analysis
- Order type analysis
- Interactive slicers and visuals for exploring data

## 💡 Key Learnings

Through this project, I practised building interactive dashboards, writing DAX calculations, organizing data for analysis, and presenting business information through meaningful visualizations.

This project helped me strengthen my practical understanding of data analytics and business intelligence using Power BI.
